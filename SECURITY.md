# Security

This repository is a teaching kit, not a hosted service. Keep keys outside tracked files. Do not paste credentials into cases, run manifests, notes, or screenshots.

The default commands are offline. The optional live transport refuses to run without an explicit execution flag, endpoint, model, key environment variable, and maximum call count. Review the provider's terms, cost, retention, and regional controls before sending any data.

Plugins run trusted local executable code with the process's permissions. Manifest validation and content hashes do not sandbox them. Review selected plugins and their dependencies before running them. Custom transports must enforce their own provider-call limits and credential handling.

Keep generated evidence outside the shared folder. Inspect Office embedded workbooks and PDF attachments as well as visible content. See `docs/sharing-review.md` for the distribution checklist.

Report concerns privately to the maintainer through an established contact channel before public disclosure. Addresses under `example.com` in this repository are fictional teaching placeholders, not working reporting contacts.
