# Talk artifacts

This folder answers one question: what can be shared with the conference audience?

`output/` contains the English nine-slide deck, a PDF export, and a printable English speaker script in DOCX and PDF. Every visible example and numerical workshop result is synthetic. The PowerPoint contains full notes for each slide.

The build scripts accept source and output paths as arguments. They do not contain the private source documents. Rebuilding requires the packages in `requirements.txt`, a compatible office converter, and the public slide images used for the script.

The chart on slide 6 is a teaching illustration. The orange replay result on slide 7 comes from the repository's authored offline fixtures. Neither is a live-model performance claim.
